# VulnFlow
Orquestador de pentesting en Python. Lanza Nmap, Gobuster, ffuf o Metasploit contra un activo autorizado, captura la salida completa y te deja marcar cada hallazgo con su evidencia para generar automáticamente un informe técnico Markdown + PDF firmado digitalmente (Ed25519). Panel web oscuro y offline · PostgreSQL/SQLite · integración NVD-CVE.
